# CodeForge

Ad-free, lightweight C & C++ compiler for Android.
Built by Taksh Rana (ranataksh63@gmail.com).

Palette: #556b2f olive, charcoal, black, gray, white.

## Get the APK (from your phone)
1. Unzip this project.
2. Run `push_to_github.py` in Pydroid 3 (needs a GitHub token with `repo` + `workflow` scopes).
3. On GitHub: Actions tab > latest "Build APK" run > download the `CodeForge-APK` artifact.
4. Unzip the artifact and install the `.apk` (allow "install unknown apps").

`app-release.apk` is the smaller one. If it ever fails to install, use `app-debug.apk`.
